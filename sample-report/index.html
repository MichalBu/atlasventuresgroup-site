What you are looking at, precisely

  • The ledger is synthetic. "Northgate Plumbing & Heating LLC" is not a real company. We generated a fictional contractor's year - 4,714 ledger lines across 23 accounts - in QuickBooks General Ledger export format. No client data appears anywhere on this site.
  • The findings are not. The file was handed to the real engine and the report is whatever it returned. Nothing was written by hand, reordered, or removed because it read badly.
  • The faults were planted, and that is the point. We built a file with the errors cleanups actually turn up - eight months reconciled and four not, transactions parked in "Ask My Accountant", an Opening Balance Equity balance nobody cleared, two double-entered bills, one vendor under several spellings. A demo on a clean file would prove nothing.
